# 童心日记微信小程序

这是原生微信小程序项目，不是 H5 网页套壳。

## 在微信开发者工具打开

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹 `wechat-miniapp`。
3. `project.config.json` 已配置当前小程序测试号 AppID。
4. 开发阶段在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 点击“编译”，先在模拟器验证页面和接口。

## 后端地址

`utils/config.js` 当前连接本机局域网地址 `http://192.168.31.59:5178`，开发者工具模拟器和连接同一 Wi-Fi 的手机都可使用。电脑网络变化后需要更新这里的 IP。

手机真机不能把 `127.0.0.1` 当作电脑。真机测试需要二选一：

- 手机和电脑在同一个 Wi-Fi，把地址改成电脑局域网地址，例如 `http://192.168.1.10:5178`，并在开发版小程序中打开调试；
- 给现有 Node 服务配置 HTTPS 测试域名，并在小程序后台加入 `request` 和 `uploadFile` 合法域名。这是更稳定的方式。

后端密钥继续保存在服务器 `.env`，不得写进小程序代码。

## 当前原生链路

开始说 → 原生录音自动分段 → 腾讯语音转文字 → 千问实时事实与追问 → 我说完啦 → 事实审计与主谓宾成文 → 语音修改 → 重新成文与校验。
