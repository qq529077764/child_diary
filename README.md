# 童心日记

面向 5-9 岁儿童的语音日记 MVP。孩子点击开始后持续讲述，系统实时转写、抽取事实并给出补充问题；结束后使用事实约束生成日记，也支持语音纠正。

## 当前核心流程

开始说 → 实时语音转文字 → 实时事实抽取与追问 → 我说完啦 → 事实约束成文 → 语音修改 → 保存

## 项目结构

- `wechat-miniapp/`：原生微信小程序
- `server.js`：本地 Node.js 接口服务
- `assets/`：小耳朵兔界面素材
- `mvp-product-spec.md`：MVP 产品说明书
- `tongxin-diary-mvp.html`：网页版交互原型

## 本地运行

1. 将 `.env.example` 复制为 `.env`，填写腾讯云语音识别和通义千问配置。
2. 运行 `node server.js`，默认端口为 `5178`。
3. 将 `wechat-miniapp/utils/config.js` 中的地址改为电脑当前局域网 IP。
4. 使用微信开发者工具导入 `wechat-miniapp/`，编译后进行真机测试。

手机与电脑需连接同一个 Wi-Fi。开发阶段需要在微信开发者工具中关闭合法域名校验；正式上线时应改用 HTTPS 服务和已配置的小程序合法域名。

## 安全说明

真实密钥只保存在本地 `.env` 中，不得写入小程序或提交到 Git。仓库中的 `.env.example` 仅包含空白配置模板。
